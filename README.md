# 📝 StudyNote

Desain antarmuka (UI) aplikasi **catatan sekolah dan pengingat tugas** untuk siswa SMA/SMK. Aplikasi ini membantu siswa mengumpulkan tugas dari semua mata pelajaran, menyimpan ringkasan materi, dan mengatur pengingat supaya tidak ada tugas yang terlewat, semuanya dalam satu tempat.

Repository ini berisi **file desain Figma** beserta **ekspor SVG** dari setiap layar aplikasi.

## 🚀 Cara Melihat Desain

**Lewat Figma**
1. Buka [figma.com](https://www.figma.com/) dan masuk ke akunmu.
2. Pilih **File → Import** (atau seret `note-app.fig` ke halaman Drafts).
3. Buka file tersebut untuk melihat dan mengedit semua layar.

**Lewat SVG**
- Buka file `.svg` langsung di browser, atau seret ke Figma, Illustrator, atau Inkscape.
